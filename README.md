# Hitting Sound

**Hitting Sound** is a small client-side Fabric mod for Minecraft 26.3. It plays a satisfying pling sound when you land a fully charged sword hit on another player.

This project is an independent clean-room implementation inspired by the behavior of the abandoned **PvP Hit Sound** mod. The original mod is marked **All Rights Reserved**, so no original source code or assets are copied into this project.

## Requirements

- Minecraft **26.3**
- Fabric Loader **0.19.5+**
- Fabric API
- Java **25**
